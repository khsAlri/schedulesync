# schedulesync

스케줄관리 시스템

## 테트리스 웹 게임

`tetris/` 폴더에 별도 설치 없이 브라우저에서 바로 실행되는 간단한 테트리스 게임이 들어 있습니다.

### 실행 방법

- `tetris/index.html` 파일을 브라우저로 열면 바로 플레이할 수 있습니다.
- 또는 로컬 서버로 실행할 수 있습니다.

  ```bash
  cd tetris
  python3 -m http.server 8000
  # http://localhost:8000 접속
  ```

### 조작법

| 키 | 동작 |
| --- | --- |
| ← / → | 좌우 이동 |
| ↑ / X | 시계 방향 회전 |
| Z | 반시계 방향 회전 |
| ↓ | 소프트 드롭 (+1점/칸) |
| Space | 하드 드롭 (+2점/칸) |
| P / Esc | 일시정지 / 계속하기 |
| Enter | 게임 시작 / 다시 하기 |

모바일에서는 화면 아래 터치 버튼으로 조작할 수 있습니다.

### 규칙

- 한 번에 지운 줄 수에 따라 1줄 100점, 2줄 300점, 3줄 500점, 4줄 800점을 받고, 여기에 현재 레벨을 곱합니다.
- 10줄을 지울 때마다 레벨이 1씩 오르고 블록이 더 빨리 떨어집니다.
- 최고 점수는 브라우저(localStorage)에 저장됩니다.
